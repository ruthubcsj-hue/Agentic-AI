# RAG Research Assistant

A hands-on implementation developed during an Agentic AI workshop to explore Retrieval-Augmented Generation (RAG), semantic search, embeddings, vector indexing, and LLM-based question answering.

## Overview

This project builds a research assistant that retrieves relevant information from selected research papers and uses an LLM to generate answers based on the retrieved context.

## Research Papers

The implementation works with:

- Attention Is All You Need
- Retrieval-Augmented Generation
- ReAct: Synergizing Reasoning and Acting in Language Models

## Workflow

Research Papers
↓
PDF Text Extraction
↓
Text Chunking
↓
Text Embeddings
↓
FAISS Vector Index
↓
Semantic Search
↓
Relevant Context Retrieval
↓
LLM
↓
Grounded Answer

This project provided hands-on experience in building a retrieval-based AI application and understanding how document processing, embeddings, vector search, retrieved context, and large language models work together.
